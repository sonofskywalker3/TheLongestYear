Each supported mod's lexicon layer lives here: `<UniqueID>.inputs.json` (hand-written routes and rulings) and `<UniqueID>.answers.json` / `<A>+<B>.answers.json` (answer deltas written in-game by `tly_lexicon write`).
See `docs/lexicon-layers.md` for the file formats, the compose order and how to map a new mod.
