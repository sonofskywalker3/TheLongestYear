**Interfaces:**
- Consumes: `AuthoredBundleDef`/`AuthoredBundleCatalog` (T1), `ItemPools` incl. new pools (T2), `BundleGenerationTuning`, `PoolItem`, `BundleSpec`/`BundleSlotSpec`.
- Produces: `AuthoredBundleComposer.Compose(AuthoredBundleDef def, int absoluteIndex, ItemPools pools, BundleGenerationTuning tuning, bool nonObjectDonationsEnabled, Random rng)` → `BundleSpec?` — null when the source pool can't fill `SlotCount` distinct items (caller skips the authored candidate; safe fallback). Rules (bind):
  - Source pool mapping: FixedList → `def.FixedItemIds` (each becomes a weight-1 candidate); Artifacts/Books/Saplings/GeodeMinerals/Cooking/TapperGoods/ArtisanGoods/Forage/Fish → the matching `ItemPools` list.
  - **Gil's Trophies special-case:** pool = `nonObjectDonationsEnabled ? GilTrophies : GilTrophyRingsOnly`; shown = `tuning.TrophyShownCount`, required = `min(tuning.TrophyRequiredCount, shown)`; stacks always 1, quality 0.
  - Weighted sample WITHOUT replacement (reuse the same cumulative-weight walk semantics as `BundleSlotFiller` — extract that private sampler into a shared internal `WeightedSampler.Sample(IReadOnlyList<PoolItem>, int, Random)` static (new small file or member of the composer; if extracting from BundleSlotFiller, change it to call the shared one — behavior-identical, covered by existing filler tests).
  - `SeasonSpread: true` (Four Seasons Sampler): after sampling, the chosen slots' pooled `Seasons` must cover ≥ 3 distinct seasons (an any-season item counts as all four); if not, re-sample up to 8 attempts with the same rng stream, else return null.
  - Slots: stack 1, quality `def.QualityAsk`. Resulting `BundleSpec`: `Room = def.Room`, `Index = absoluteIndex`, `Name = DisplayName = def.Name`, `RewardField`, `Color`, `NumberOfSlots`, no PickCount (composed slots are final — `PickCount: -1`).
